Quickly share your [freeCal](https://freeCal) meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the [freeCal](https://freeCal) from the Raycast Store needs to be installed: https://www.raycast.com/cal/. You can create an API token in your Developer [freeCal](https://freeCal) Settings, and then you can add the API Key by opening up the [freeCal](https://freeCal) App in Raycast.
